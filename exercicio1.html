Seletores em HTML

Os seletores são padrões ou comandos usados para "encontrar" e escolher elementos de uma página para que eles recebam estilos visuais no CSS ou manipulação no JavaScript.

SELETOR DE ATRIBUTO

Um seletor de atributo (usado no CSS para direcionar elementos HTML) é um recurso que permite selecionar e estilizar elementos com base na presença de um atributo ou no valor desse atributo.

SELETOR DESCENDENTE

O seletor descendente é um recurso do CSS (usado para estilizar documentos HTML) que permite selecionar elementos que estão dentro de outros elementos (ancestrais), independentemente de quão profundos eles estejam na árvore do DOM (Document Object Model).

SELETOR FILHO DIRETO

O seletor filho direto (representado pelo sinal de maior que >) é um recurso do CSS usado para estilizar apenas os elementos que estão imediatamente abaixo de um elemento pai, ignorando netos ou outros descendentes mais profundos.

SELETOR ADJACENTE DIRETO

O seletor de irmão adjacente (representado pelo sinal de mais + em CSS) é um combinador usado para estilizar um elemento que aparece imediatamente após outro elemento específico na estrutura do documento.

SELETOR ADJACENTE DIRETO

O seletor de irmão adjacente (representado pelo sinal de mais + em CSS) é um combinador usado para estilizar um elemento que aparece imediatamente após outro elemento específico na estrutura do documento.

SELETOR DE IRMÃOS GERAIS

O seletor de irmãos gerais (representado pelo símbolo ~ em CSS) seleciona todos os elementos que vêm depois de um elemento de referência e que compartilham o mesmo elemento pai.

SELETOR DE PSEUDOCLASSE

Uma pseudo-classe é uma palavra-chave adicionada a um seletor CSS (e não HTML diretamente) que especifica um estado especial ou uma condição específica do elemento selecionado.

SELETOR DE PSEUDOELEMENTO

Um pseudo-elemento é uma palavra-chave adicionada a um seletor CSS que permite estilizar uma parte específica ou criar um elemento visual dentro de um elemento HTML existente, sem precisar alterar a estrutura do documento no DOM.
